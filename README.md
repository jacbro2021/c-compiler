# C-Compiler 

This project is a c compiler for a subset of the C programming language. The compiler currently has support for basic language constructs such as functions and statements. It also has support for basic types
(int, char, and limited support for void).

The project was adapted from the guides provided in the following repositories 

- [https://github.com/DoctorWkt/acwj "A Compiler Writing Journey"]
- [https://www.t3x.org/subc "SubC Compiler"]
